# 클라우드 펀딩 칩 투자 웹서비스

학생은 닉네임과 모둠을 정해 입장하고, 칩 3개(실현 가능성·창의성·사회 공헌)를 발표를 들으며 다른 모둠에 줍니다.
교사는 대시보드에서 모둠별 칩 종류와 개수를 실시간으로 봅니다. 외부 패키지 없이 Node.js(18 이상)만 필요합니다.

## 1. 교실에서 바로 실행 (교사 노트북)
    node server.js

- 학생 접속: http://노트북IP:3000/  (같은 와이파이여야 해요. 학교망이 기기 간 접속을 막으면 2번을 쓰세요.)
- 교사 대시보드: http://노트북IP:3000/teacher  (PIN은 서버를 켤 때 화면에 나와요)
- PIN을 직접 정하려면: TEACHER_PIN=2580 node server.js

## 2. 인터넷에 올려서 쓰기 (Render 무료 서버 예시)
1. 이 폴더를 GitHub 저장소로 올립니다.
2. render.com → New → Web Service → 저장소 선택
3. Build Command는 비우고, Start Command는 `node server.js`
4. Environment에 TEACHER_PIN (예: 2580)을 추가
5. 만들어진 주소를 학생에게, 주소 뒤에 /teacher 를 붙인 주소를 교사가 사용
- 무료 서버는 한동안 쓰지 않으면 잠들어요. 수업 5분 전에 한 번 열어 두세요.

## 규칙(수정은 server.js)
- 칩은 학생 1명당 3종류 1개씩. 우리 모둠에는 줄 수 없어요.
- 칩을 준 뒤에도 다른 모둠으로 옮기거나 '되돌리기'가 가능해요(투자 중일 때).
- 교사는 '투자 잠시 멈추기'로 칩 주기를 막을 수 있고, 모둠 수(2~10)를 바꿀 수 있어요.
- 같은 닉네임은 같은 모둠일 때만 다시 들어올 수 있어요(새로고침·재접속 대비).
- 기록은 data.json에 저장되어 서버를 다시 켜도 이어져요. '처음부터 다시'로 초기화해요.
